# OneBlock Cobblemon - Líderes (mod)

Por Zennin - https://www.youtube.com/@Zorikzennin - Todos los derechos reservados (ver LICENCIA.txt).

Qué hace:
- Agrega el tipo de equipo `oneblock:espejo` para NPCs de Cobblemon: el NPC copia el equipo
  del jugador que lo desafía (lo usa el Líder Espejo de la isla 1).
- Hace que los NPCs megaevolucionen cuando pueden (la IA de Cobblemon no lo hace sola).

Necesita: Minecraft 1.21.1, Fabric, Fabric API, Fabric Language Kotlin, Cobblemon 1.8.x.

## Cómo sacar el .jar (sin instalar nada)
1. En GitHub, crear un repositorio **privado** (que el código no quede a la vista).
2. "Add file > Upload files" y arrastrar TODO el contenido de esta carpeta, incluida `.github`.
3. Ir a la pestaña **Actions**: arranca solo. Cuando termina en verde, entrar a la ejecución y
   bajar el artifact `oneblock-lideres`. Adentro está el .jar para la carpeta `mods`.
